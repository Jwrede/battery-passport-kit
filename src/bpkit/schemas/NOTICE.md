# Battery passport JSON schemas

The JSON schema files in this directory are the BatteryPass-Ready data model, version 2.0.1,
copied unchanged from https://git.gefeg.com/bp/BatteryPassDataModel (folder
`JSONSchemaFiles/v2.0.1`, retrieved 2026-10-18).

Attribution 4.0 International licence (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/.
The resources are maintained by acatech on behalf of the BatteryPass-Ready Consortium.

The consortium marks the model as work in progress. Some data elements are mandatory only under
conditions that the schemas cannot express (see `CONDITIONAL_ELEMENTS` in `bpkit/schema.py`).
